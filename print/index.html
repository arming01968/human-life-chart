How to get true camera-ready (offset)

  1. Open the PDF in Adobe Illustrator or Affinity Designer
  2. Document Setup → Add 0.125" bleed all around, check Trim Marks
  3. Select all text → Type → Create Outlines (so fonts are embedded)
  4. Edit → Convert to CMYK: U.S. Web Coated (SWOP) v2
  5. Save As → PDF/X-1a:2001 with bleeds and marks

Most digital large-format shops (FedEx, Staples, local blueprint shop) will accept the RGB PDF as-is. Only offset litho needs CMYK conversion.
