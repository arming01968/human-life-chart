# The Human Life — Biography Chart — GitHub Pages Ready

This folder is ready to push to GitHub Pages.

Structure:
- / = clean poster (index.html)
- /writable/ = typeable version with localStorage auto-save
- /print/ = print-ready PDF and download assets
- /assets/ = images and PDFs

## Deploy:

1. Create a new repo on GitHub (e.g. `human-life-chart`)
2. Upload everything in this folder to the repo root
3. Go to Settings > Pages > Build and deployment > Deploy from main branch, root folder
4. Save — live at https://yourusername.github.io/human-life-chart/

## Printing:

- `assets/Human_Life_Biography_Map_PrintReady.pdf` is 24x36" with 0.125" bleed, 300 DPI, RGB.
- For offset printing, open in Illustrator → convert to CMYK → save as PDF/X-1a.

Based on George & Gisela O'Neil / Florin Lowndes concept from The Human Life.
